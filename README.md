
# CodeAlpha Task 2 - Exploratory Data Analysis

## Project Title

E-Commerce Sales Exploratory Data Analysis

## Internship

CodeAlpha Data Analytics Internship

## 1. Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on an e-commerce sales dataset.

The objective is to understand sales patterns, identify trends, analyze product performance, and generate meaningful business insights using Python.

## 2. Objectives

- Understand the structure of the dataset
- Identify missing values and duplicate records
- Analyze product-wise sales
- Analyze category-wise sales
- Analyze city-wise sales
- Identify monthly sales trends
- Generate meaningful business insights
- Create visualizations for data interpretation

## 3. Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- VS Code

## 4. Dataset Description

The project uses a generated sample e-commerce sales dataset containing 500 records.

The dataset includes the following columns:

- Order_ID
- Order_Date
- Product
- Category
- City
- Quantity
- Unit_Price
- Sales

Additional date-based columns were created during analysis:

- Year
- Month
- Month_Name

## 5. Data Analysis Process

1. Dataset creation and loading
2. Dataset structure analysis
3. Data type inspection
4. Missing value detection
5. Duplicate record detection
6. Data cleaning
7. Date-based feature creation
8. Product-wise sales analysis
9. Category-wise sales analysis
10. City-wise sales analysis
11. Monthly sales trend analysis
12. Business insights generation

## 6. Key Findings

- Laptop generated the highest total sales.
- Bangalore recorded the highest city-wise sales.
- May recorded the highest monthly sales.
- Electronics was the highest-sales category.
- Mouse recorded the lowest product-wise sales.
- The dataset contained no missing values.
- The dataset contained no duplicate records.

## 7. Visualizations

The project includes the following charts:

- Total Sales by Product
- Total Sales by Category
- Total Sales by City
- Monthly Sales Trend
- Quantity Distribution
- Sales Distribution by Category
